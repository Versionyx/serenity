# Serenity

> A precision combat game inspired by fencing and Hapkido.

## 🎮 About

Serenity is a game developed for the LuisCanary Game Jam #3.

The player is a former fencing and Hapkido master who must restore peace in a world where violence has become the law.

## ⚔ Features

- Precision fencing combat
- Hapkido-inspired deflections
- Serenity combat system
- EMP bow against cyborg enemies
- Boss fights

## 🛠 Engine

- Godot 4
